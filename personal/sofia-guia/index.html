🔢 Técnicas de Conteo

¿Usa TODOS los elementos?
SÍ PERMUTACIONES
NO VARIACIÓN / COMBINACIÓN

Permutaciones (usa todos)

Pn = n! — orden, sin repetir
Pc = (n−1)! — circular, mesa redonda
PR = n! / (a!·b!·...) — con repetición (anagramas)

Variación vs. Combinación

VARIACIÓN — orden SÍ importa
VR(n,r) = nr  ·  V(n,r) = n! / (n−r)!
COMBINACIÓN — orden NO importa
CR(n,r) = (n+r−1)! / ((n−1)!·r!)
C(n,r) = n! / ((n−r)!·r!)
VR/CR = con repetición · V/C = sin repetición

Casos especiales

Grupos por categoría (ej: 2 hombres + 3 mujeres):
Calcula cada categoría aparte y multiplica:
C(4,2) × C(5,3) = 6 × 10 = 60
Despejar n (ej: C(n,2) = 36):
n(n−1) / 2 = 36 → n(n−1) = 72 → n = 9

¿Orden importa? — Regla definitiva

Mira el resultado final:
SÍ importa si cuentan como diferentes:
P,R,T ≠ P,T,R ≠ R,P,T → 3 resultados
→ variación / permutación
NO importa si cuentan como el mismo:
pera,pera,manzana = manzana,pera,pera
→ combinación
Ejemplos típicos:
• Palabras, códigos, podio → SÍ
• Comité, equipo, grupo, frutas → NO

Atajos con factoriales

  • No expandas el factorial entero. Cancela contra el factorial más grande del denominador:
    7! / (4!·3!) = (7·6·5·4!) / (4!·3!) = 7·6·5 / 6 = 35
  • Cancela ANTES de multiplicar. Evita calcular 5040, 720, etc.
  • Con números chicos, multiplicación directa: C(4,2) = 4·3 / 2 = 6 (sin escribir toda la fórmula)
  • Si te da decimal raro o número enorme → revisa la cancelación.

🎲 Probabilidad

¿Aparece "dado que" o "sabiendo que"?
SÍ CONDICIONAL
NO SIMPLE
= casos / total
📌 Notación: P(A|B) = "probabilidad de A, dado B".
La barra NO es división. El libro a veces escribe P(A/B) pero significa lo mismo.

Las 3 fórmulas

Intersección (multiplica):
P(A∩B) = P(A) · P(B|A)
Condicional (divide):
P(B|A) = P(A∩B) / P(A)
Bayes (invierte condicional):
P(B|A) = P(B) · P(A|B) / P(A)

Cuándo usar cada una

Te dan…Te piden…Usa
P(A∩B), P(A) P(B|A) Condicional
P(A), P(B), P(A|B)
SIN intersección		 P(B|A) BAYES
P(A), P(B|A) P(A∩B) Multiplica

Truco "dado que"

"Dado que B" elimina todo lo que NO es B.
Nuevo universo = B. Calcula dentro de B.
Ejemplo: dado, B = par → universo nuevo = {2, 4, 6}.
¿Múltiplo de 3? Solo {6} → P = 1/3

Diagrama de Venn

Universo = total (100%) · A∩B = en ambos
"Dado que A" → solo miras dentro del círculo A

Pasos para resolver condicional

  • Define A y B (¿qué evento es cuál?).
  • Localiza la palabra "dado que" → eso va al denominador.
  • ¿Te dan la intersección? → usa fórmula condicional.
  • ¿No te dan la intersección pero sí condicional al revés? → Bayes.
  • Si hay porcentajes, multiplica por 100 personas para visualizar mejor.

⚠️ Errores comunes (los que vimos hoy)

  • La barra | o / en P(A|B) NO es división — es "dado que".
  • No expandas el factorial completo → cancela contra el factorial más grande del denominador.
  • Confundir "y" (multiplica) con "dado que" (divide).
  • Olvidar cancelar ambos factoriales del denominador.
  • Tratar grupo mixto (4H + 5M) como uno solo → calcula cada categoría aparte y multiplica.
  • Usar Bayes sin necesidad → si te dan la intersección, basta condicional simple.
