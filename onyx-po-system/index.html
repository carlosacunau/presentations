01 // El estado actual

Cuatro formatos,
un proceso manual

Cada cliente tiene su propio sistema. Ninguno habla el mismo idioma que Odoo.

  • Revisión manual de 8 a 10pm
    Un agente filtra todos los correos entrantes con POs y los distribuye a Customer Service.
  • 4+ formatos distintos de PO
    QuickBooks, Unifirst Solutions, correo manual, Excel. Cada cliente escribe diferente.
  • Códigos de producto no coinciden
    El nombre del cliente para el producto ≠ el código interno de Onyx. Traducción manual.
  • Tallas a veces escritas a mano
    Algunos sizing forms llegan en papel. OCR + validación humana requeridos.

Capacidades del sistema

02 // La solución

Lo que hace el sistema

Lectura multi-formato

PDFs de QuickBooks, Unifirst Solutions, correos de texto, Excel. Si lo puede leer un humano, lo puede leer el sistema.

QuickBooks PDF Unifirst Manual text Excel

Mapeo de códigos de cliente

El sistema aprende la equivalencia entre el código del cliente y el SKU interno de Onyx. Se actualiza cuando cambian.

OCR + validación de tallas

Si las tallas vienen escritas a mano o en imagen, el sistema intenta leerlas. Si no puede, alerta a Javier para revisión manual de ese ítem.

Digest diario de aprobación

Cada mañana llega un correo con todas las órdenes parseadas, clasificadas y listas. Javier revisa, aprueba, y se cargan en masa.

Integración con Odoo

03 // Integración

Conectado directo
a Odoo vía MCP

Existe un MCP oficial de Odoo. Eso significa que el sistema puede crear, leer, actualizar y eliminar registros en Odoo hablándole en lenguaje natural.

Hoy: Excel para carga masiva manual.
Fase 2: carga directa automática con aprobación de un click.

  • Create — Crear órdenes de compra en Odoo
  • Read — Consultar stock, precios pactados, estatus
  • Update — Modificar una orden si hay cambio del cliente
  • Bulk upload — Cargar N órdenes en una sola operación
  • Alertas — Notificar si una orden tiene inconsistencias vs. precios pactados

MCP disponible en apps.odoo.com · avalado por Odoo

Human in the loop

04 // Control y confianza

El sistema automatiza.
Javier aprueba.

La IA no sube nada a Odoo sin revisión humana. La idea no es reemplazar al equipo — es que el equipo no pierda tiempo en lo que la máquina puede hacer mejor.

Lo que hace la IA

Lee, parsea, mapea códigos, organiza por prioridad, genera el Excel de carga. Sin errores tipográficos, 24/7, en segundos.

Lo que hace Javier

Revisa el digest de 5 minutos. Si todo está bien, aprueba. Si algo se ve raro, lo corrige antes de subir. Punto.
