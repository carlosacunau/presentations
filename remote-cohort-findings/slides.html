04 // How a skill is built

Three parts

1. Operating stance

3 to 4 absolutes. "No dollars, no case." Tells the AI how to think, not just what to output.

2. Template

The fill-in shape: a one-pager, a checklist, a scorecard.

3. Refuse

The anti-patterns it pushes back on. This is where judgment gets encoded.

Write the Refuse list first. It forces you to name what "good" rules out. And keep it tight: 30 lines that enforce one thing beat 300 nobody trusts.

05 // What's missing

The four big gaps

Gap

No examples

Pure zero-shot, no worked example anywhere. Fix: add one filled-in example per template. The course teaches few-shot.

Gap

Refuse has no recovery

It says what to refuse, not what to do instead. Fix: pair every refuse with a redirect ("if numbers missing, ask for these two").

Gap

No "ask before guessing"

They jump straight to output. Fix: add "if unknown, ask first." The course calls this Plan, Then Execute. Highest-leverage line you can add to ANY skill.

Gap

Hidden connector needs

Skills assume Vitally / Zendesk data, but neither has an MCP at Remote. Fix: add a "Requires:" line so you know when it falls back to manual.

05 // What's missing

Three more

Gap

Overlap

cs-ai-copilot duplicates checklists from comms and lifecycle. Skills should compose, not copy.

Gap

Route ops skills through the Remote MCP where Vitally / Zendesk aren't reachable. A fix you can make today.
