05 // Building Blocks

Skills, MCPs, APIs

Skills

SOPs you teach Claude once. Things you do repeatedly -- like summarizing data, formatting exports, or running a specific workflow. Write it once, run it forever.

Example: "Import PropStream CSV and tag by neighborhood"

MCPs

Pre-built servers that connect Claude to external tools. Gmail, Google Sheets, browser control, DevTools. Not one SOP -- a whole set of capabilities already wired up.

Example: Playwright MCP controls a browser for you

APIs

How apps talk to each other behind the scenes. Every website (PropStream, MGO Connect) has one. We find it, document it, and let Claude call it directly.

Example: MGO Connect's hidden API for permit queries
