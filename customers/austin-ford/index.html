05 // Building Blocks

Skills, MCPs, APIs

Skills

SOPs you teach Claude once. Things you do repeatedly -- write it once, run it forever. I have 48 of these. They're just .md files you can share and open in Cursor.

Example: "Summarize YouTube videos", "Create presentations", "Discover hidden APIs"

MCPs

Pre-built servers with multiple tools baked in. Google Workspace MCP does Gmail + Calendar + Drive. Playwright MCP controls a browser and monitors network traffic.

A skill = one SOP. An MCP = a whole toolbox.

APIs

How apps talk to each other behind the scenes. Every website has one -- PropStream, MGO Connect. We find it by watching the network traffic, then call it directly.

If the app doesn't publish docs, we reverse-engineer it.
