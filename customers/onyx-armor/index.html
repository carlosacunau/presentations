02 // The Problem

2 Hours.
Every Night.

Javier Rocha reads POs from emails at 8–10 PM, manually translating each dealer's format into Odoo line items. Recently lost 4 staff, replaced 1.

  • Three incompatible formats
    Premier, T&T, and Read's each send POs in a completely different format with different measurement conventions.
  • Manual SKU translation
    Dealer product names don't match Onyx's internal Odoo SKUs. Javier maps them from memory.
  • No buffer, no audit trail
    One missed line item means a wrong order ships. No history of what was entered, when, or by whom.
  • Error risk compounds at volume
    ~90% of orders flow through 3 dealers. Batch POs (13+ officers) are entirely manual today.

03 // OCR Strategy

Hybrid PDF
Routing

All current dealer PDFs are digital (text-layer). Mistral OCR is wired in as a fallback — triggered only when no text layer is detected.

Cost at current volume:

pdfplumber — free, local
Mistral OCR — ~$1–2 / 1K pages (fallback only)

Routing Logic
✓
Text layer detected
pdfplumber extracts text + tables → Claude Haiku structures output
⤷
No text layer (scanned)
Mistral OCR API preserves table structure as markdown → Claude Haiku structures output
Why Mistral OCR over Claude Vision
  • Purpose-built for documents — preserves column layout and table structure as markdown
  • Flat per-page rate vs. per-token cost (cheaper on dense scanned pages)
  • Better upstream structure = less correction work for Claude downstream

03 // Capabilities

What the System Does

AI-Powered Parsing

Claude Haiku reads raw PDF text and outputs a structured JSON order — PO number, officer names, products, measurements, shipping address.

Automatic SKU Mapping

Fuzzy-matches dealer product names to Onyx's Odoo SKUs. High-confidence matches apply automatically; low-confidence go to Javier for one-time resolution — and learn from each answer.

Human Review UI

HTMX queue shows parsed orders alongside the original PDF. Javier edits any field, approves with one click. No Odoo data entry until he signs off.

Odoo-Ready CSV

Approved orders export as CSV mapped to Onyx's exact Odoo column headers. Daily digest email summarizes processed orders and flags any failures.
