07 // La metáfora

Enseñar a pescar vs. entregar el pescado

VSCode = enseñar a pescar

Workshops. La persona aprende a estructurar pedidos, a generar sus propios skills, a pensar en automatización. Útil para quien quiere meterse de verdad.

Cowork = entregar el pescado

Le instalamos su sistema operativo de empresa. Carpetas, skills, conectores ya armados. La persona presiona un botón y trabaja. Es donde está el servicio recurrente.

La gente no adopta inteligencia artificial a nivel empresa. La adopta a nivel personal. Por eso Cowork se instala en el equipo de cada uno, y cada uno siente que tiene su asistente.

09 // El truco técnico

Hidden API +
printing-press

Cuando la herramienta del cliente no expone API pública, no nos quedamos atascados.

  • Hidden API: Playwright + consola de desarrollador. Claude observa cómo se habla la app consigo misma y documenta sus endpoints.
  • printing-press: repo nuevo, ~2 semanas, ~2.300 stars. Convierte cualquier app sin API en un CLI con el que Claude Code se comunica directo.

El valor agregado

Yo me conecto a las fuentes de datos del cliente desde el backend. El cliente no ve la complejidad ni asume el riesgo de seguridad. Nosotros lo cubrimos, ellos solo consultan desde Cowork.

El riesgo del open

Hace poco se filtraron ~40.000 contraseñas por instalaciones mal hechas. Por eso Cowork le gana a soluciones tipo OpenCloud para empresas medianas: punto medio seguro.

11 // Yorhman lo aterrizó

Hay dos tipos de cliente

Cliente elaborado

Tiene estructura, ya vio cosas, confía después de demostrarle. Pide su asistente virtual a la medida.

Ticket: 2K a 4K USD / mes.

Cliente con data dormida

Tiene ERP, CRM, sistema de manufactura, y no sabe qué hacer con la data. La mayoría del mercado. Ejemplo: la gente de Onyx.

Argumento: "una persona en USA te cuesta $2.5K-3K al mes. Nosotros te cobramos $1K, con alertas, 24/7." Sin tecnicismos.

"A la larga, a ellos no les importa cómo funciona. Lo importante es que funcione." (Yorhman)
