06 // Architecture

Technical Architecture

Customer

Discord

Phone + laptop — only app they touch

Claude Code CLI

Background daemon, auto-starts on login, heartbeat every 30s

VPS — 24/7

GoBot + Router

Captures messages, routes based on CLI status

Supabase

Per-customer data, RLS isolation

Scheduled Jobs

Daily brief, metrics, monitoring

Carlos (IDE)

Build & Deploy

Skills, services, MCP endpoints → push to VPS

Monitor

Heartbeats, task queues, errors across all customers

Subscription-first routing: CLI online = subscription (free) · CLI offline = Haiku API (cheap) or queue · Customer installs 2 things: Discord + CLI
